# Вовлечение новых пользователей: почта, цепочка писем, онбординг

Linear: WOK-636 (родитель WOK-561 «Промо Vezdepost»).

## Зачем

На 2026-10-21 из 19 регистраций 15 не подключили ни одного канала, публикует
только один пользователь кроме владельца. Приток уже есть (3 регистрации из
ChatGPT за 19–21.10), люди теряются сразу после регистрации. Промо без этого
льёт трафик в дырявое ведро.

Что нашли:

- на проде не настроена почта (`EMAIL_PROVIDER` пуст) — не уходит ни одно
  письмо, включая сброс пароля;
- онбординг — модалка из трёх шагов Postiz: «Подключите каналы» → «Подключите
  ИИ-агента» (MCP, API-ключи — непонятно SMM-специалисту) → англоязычное
  видео Postiz. Потом пустой календарь без подсказок;
- нет ни одного письма-напоминания; Telegram-бот @vezde_post_bot только
  отвечает.

## Цели

1. Сброс пароля и прочие системные письма работают.
2. Новичок получает короткую цепочку писем от автора, которая ведёт к первому
   каналу и первому посту и приглашает ответить.
3. Онбординг в приложении ведёт к самому простому первому каналу (Telegram или
   MAX) и не отвлекает на MCP.
4. Если пользователь привязал бота-ассистента (Telegram или MAX), напоминания
   дублируются туда.

Не цели: маркетинговые рассылки по всей базе, A/B-тесты, письма для
существующих пользователей (им владелец пишет лично), собственный редактор
шаблонов.

Анти-цели: спам (письмо после того, как человек уже публикует), лишний шаг
активации, который отсечёт ещё часть новичков, утечка адресов в публичный
репозиторий.

## Решения

- **Провайдер — Unisender Go по SMTP** (выбор владельца). Почему: российский
  сервис, данные остаются в РФ (совпадает с «хостинг в РФ» на лендинге), оплата
  в рублях. Отвергли Resend (зарубежный, вопрос 152-ФЗ и оплаты) и Яндекс 360
  (платно, лимиты). Подключение через уже существующий `nodemailer`-провайдер,
  без нового кода провайдера.
- **Отправитель — «Дмитрий из Vezdepost»**, ответы приходят владельцу
  (выбор владельца). Адрес для ответов задаётся переменной окружения
  `EMAIL_REPLY_TO` на сервере, в репозиторий не попадает.
- **Активация по почте не включается** (решение Claude). Как только
  `EMAIL_PROVIDER` задан, код Postiz требует подтвердить почту при регистрации
  по паролю; при 3 регистрациях в неделю это ещё одна точка отвала. Новая
  переменная `EMAIL_ACTIVATION_DISABLED=true` сохраняет авто-активацию;
  приветственное письмо служит мягкой проверкой адреса. Отвергли: оставить
  поведение Postiz (лишний шаг), отключить почту для активации целиком
  (то же самое, но без явного флага).
- **Цепочка — Temporal workflow на пользователя**, по образцу
  `personalStreakReminderWorkflow` (решение Claude). Отвергли cron-скрипт на
  сервере (вне кода приложения, не тестируется) и внешнюю платформу рассылок
  (адреса уходят третьей стороне, лишняя интеграция).
- **Отписка — флаг `User.sendOnboardingEmails` (default true)** и ссылка с
  подписанным токеном в каждом письме цепочки (решение Claude). Колонка с
  default — безопасна для `db push`.
- **Обвязка писем на русском**: подвал общего шаблона `sendEmailSync` и тексты
  активации/сброса пароля переводятся (решение Claude: продукт русскоязычный,
  английский подвал в русском письме выглядит как спам).

## Цепочка писем

Запускается при создании пользователя (регистрация по паролю и через OAuth),
только для новых пользователей с момента деплоя. Каждый шаг перед отправкой
перечитывает состояние; цепочка заканчивается, как только у организации есть
хотя бы один пост (любой, кроме удалённого), или пользователь отписался,
отключён, удалён.

| Когда | Условие | Тема | Суть |
|---|---|---|---|
| через 10 мин | всегда | Привет! Я Дмитрий, автор Vezdepost | кто я, зачем сервис, начните с Telegram или MAX — 2 минуты, ссылки на гайды; «ответьте на письмо, если что-то не получится — читаю сам» |
| через 1 день | нет каналов | Подключите первый канал за 2 минуты | три ссылки: Telegram, MAX, VK; кнопка «Открыть Vezdepost» |
| через 3 дня | нет каналов | Что-то не получилось? | короткое личное письмо: «напишите в ответ, что пошло не так, помогу» |
| через 1 день после первого канала | канал есть, постов нет | Как запланировать первый пост | 3 шага, ссылка на календарь, про бота «постить из Telegram» |

Тексты — в коде, в одном модуле (`onboarding.emails.ts`), простое HTML без
картинок. Ссылки на гайды — статьи блога `https://vezdepost.ru/blog/<slug>/`
(`otlozhennyj-post-v-telegram`, `otlozhennyj-post-v-max`,
`otlozhennye-posty-vk`).

Telegram/MAX: если у пользователя есть `TelegramAssistantLink`, тот же шаг
отправляется короткой версией через бота-ассистента соответствующего
транспорта (без отписки — бот можно отвязать).

Workflow id `onboarding_<userId>`, `workflowIdConflictPolicy: USE_EXISTING`
(повторный старт ничего не ломает). Ошибка отправки одного шага не роняет
цепочку.

## Онбординг в приложении

- Шаг «Подключите ИИ-агента» убирается из модалки (MCP остаётся в
  Настройки → Агенты).
- Шаг 1 «Подключите каналы»: над списком подсказка «Проще всего начать с
  Telegram или MAX — 2 минуты» со ссылками на гайды.
- Шаг «Смотреть обучение» (видео Postiz на английском) заменяется шагом
  «Готово»: кнопка «Постить из Telegram» (существующая привязка ассистента) и
  ссылки на гайды.
- Пустое состояние календаря («Каналов нет»): добавить ссылку «Как подключить
  канал» на гайды.

Строки — через `t()` с ключами в `ru` и `en` переводах.

## Конфигурация прода

Новый скрипт `docs/server-scripts/39-configure-email.sh` (по образцу других
configure-скриптов): спрашивает SMTP-логин/пароль скрытым вводом, пишет в
серверный `.env` `EMAIL_PROVIDER=nodemailer`, `EMAIL_HOST`, `EMAIL_PORT`,
`EMAIL_SECURE`, `EMAIL_USER`, `EMAIL_PASS`, `EMAIL_FROM_NAME`,
`EMAIL_FROM_ADDRESS`, `EMAIL_REPLY_TO`, `EMAIL_ACTIVATION_DISABLED=true`;
соответствующие строки добавляются в явный список env
`docker-compose.override.yaml`. Переменные без значений ничего не включают —
деплой кода до настройки почты безопасен.

Действия владельца: аккаунт Unisender Go, подтверждение домена vezdepost.ru
(SPF/DKIM-записи на reg.ru, плюс DMARC `p=none`), SMTP-пароль, запуск скрипта.

## Ручная часть (сразу, без кода)

Владелец пишет каждому новичку лично — адрес приходит в Telegram-уведомлении о
регистрации. Шаблон — в чате сессии 2026-10-21.

## Проверка

- unit-тесты: условия шагов цепочки (канал есть/нет, пост есть, отписка),
  токен отписки, флаг активации;
- на проде после настройки: регистрация тестового аккаунта, приходит письмо
  через 10 минут, сброс пароля приходит, ссылка отписки работает.

## Оставлено исполнителю

Точная формулировка писем в рамках таблицы, вёрстка подсказок в модалке,
структура модуля и тестов.
